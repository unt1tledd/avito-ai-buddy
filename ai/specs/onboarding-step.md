# Сценарий · Настройка окружения

Стажёр backend-команды спрашивает, как настроить окружение. AI-buddy находит тестовую инструкцию и объясняет шаг. После подтверждения стажёром AI-buddy отмечает шаг выполненным и возвращает сохранённый статус.

| Условие | Ожидаемое поведение |
|---|---|
| Стажёр спрашивает об окружении | Агент вызывает `find_instruction` и возвращает ответ с доступным источником. |
| Подходящего документа нет среди разрешённых | Поиск возвращает пустой список. В ответе сообщается, что доступных сведений недостаточно. |
| Найдена памятка с другой ролью или командой | Её фрагмент не попадает в контекст модели и ответ API. |
| Стажёр подтвердил `dev-environment` | Агент вызывает `complete_onboarding_step`. Сервис адаптации проверяет права, сохраняет статус и возвращает `completed`. |
| Подтверждения нет или инструмент получил другой ID | Состояние шага сохраняется без изменений. |
| Сервис отклоняет действие | Агент сообщает об ошибке. В ответе API `action` равен `null`. |
| Повторно запрошено завершение того же шага | Сервис возвращает существующий статус. Тестовая база хранит одну запись на пару пользователь–шаг. |
| Модель стала недоступна после сохранения статуса | AI-buddy возвращает подтверждённый результат и короткий текст о завершении. |

Контекст пользователя и подтверждение передаёт авторизованный сервис `chat`. Модель передаёт аргументы инструмента и получает только его результат. Сервис `onboarding` владеет состоянием шага и проверяет право на изменение.
