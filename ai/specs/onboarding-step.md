# Сценарий · Настройка окружения

Стажёр backend-команды спрашивает, как настроить окружение. AI-buddy находит тестовую инструкцию и объясняет шаг. После подтверждения стажёром AI-buddy отмечает шаг выполненным и возвращает сохранённый статус.

| Условие | Ожидаемое поведение |
|---|---|
| Стажёр спрашивает об окружении | Агент вызывает `find_instruction` и возвращает ответ с доступным источником. |
| Подходящего документа нет среди разрешённых | Поиск возвращает пустой список. В ответе сообщается, что доступных сведений недостаточно. |
| Найдена памятка с другой ролью или командой | Её фрагмент не попадает в контекст модели и ответ API. |
| Стажёр подтвердил `dev-environment` | AI-buddy передаёт подтверждённый ID в `onboarding`. Сервис адаптации проверяет права, сохраняет статус и возвращает `completed`. |
| Подтверждения нет | Вызова записи нет. |
| Сервис отклоняет действие | AI-buddy сообщает об отказе. В ответе API `action` равен `null`. |
| SQLite получает повторное подтверждение того же шага | AI-buddy возвращает существующий статус. Тестовая база хранит одну запись на пару пользователь–шаг. |
| Модель или поиск недоступны | Для подтверждённого шага AI-buddy обрабатывает результат `onboarding` напрямую. |
| После отправки запроса истёк таймаут | AI-buddy сообщает о неизвестном результате с `action: null`. Автоматического повтора записи нет. |

Идентификатор пользователя и подтверждение передаёт авторизованный сервис `chat`. В интеграции AI-buddy получает актуальный профиль из `user`. Сервис `onboarding` владеет состоянием шага и проверяет право на изменение. Модели доступен инструмент поиска `find_instruction`.
