# AI-buddy — фронтенд

Интерфейс **ИИ-помощника** для стажёров на **React**, **TypeScript** и **Vite**.

Подробное описание текущего чата, API, интерфейса, заявок на доступ и внесённых изменений: [CHAT.md](CHAT.md).

## Локальная разработка

Нужны Node.js 20 и npm. Из корня репозитория:

```sh
cd frontend
npm ci
npm run dev
```

Интерфейс доступен по адресу [localhost:5173](http://localhost:5173).

Для входа, чата и Roadmap нужен работающий API. Vite направляет запросы `/v1`,
включая WebSocket, на `http://localhost:8085`. Адрес задаётся в `vite.config.ts`.
Запуск серверных сервисов выполняется отдельно по инструкции проекта.

## Проверки и сборка

Команды выполняются из папки `frontend`:

```sh
npm test
npm run build
```

- `npm test` проверяет обработку API-ответов и состояния компонентов с имитацией HTTP.
- `npm run build` проверяет TypeScript и создаёт сборку в `dist/`.

## Структура

```text
src/
  App.tsx                       # Вход, регистрация, профиль и тема
  lib/api.ts                    # API-клиент и преобразование данных
  pages/ChatPage.tsx            # Сообщения, история чатов и уведомления
  pages/AccessProposalCard.tsx  # Карточка заявки на доступ
  pages/OnboardingPage.tsx      # Roadmap и отметки выполнения
  pages/SetupPage.tsx           # Заполнение профиля стажировки
  index.css                     # Стили и анимации
tests/                          # Тесты фронтенда
```

## Поведение интерфейса

- Регистрация и вход используют серверную сессию. При отсутствии профиля
  стажировки отображается форма его заполнения.
- «Новый вопрос» открывает новый чат; история позволяет переключаться между
  чатами и удалять их. Enter отправляет сообщение, Shift + Enter переносит строку.
- Roadmap читает назначенный план через GET `/v1/users/{user_id}/plan`, а текущие
  шаги и названия треков — через GET `/v1/users/{user_id}/plan_context`. Самостоятельно
  план не создаёт. Выполнение и снятие выполнения сохраняются через PUT/PATCH
  `/v1/step/{user_id}/{step_id}/completion`, затем перечитываются план и контекст.
  Для отметки используются круглые кнопки с галочкой рядом с шагами. После
  выполнения открытого текущего шага выбирается следующий шаг того же трека
  из нового `plan_context`, если сервер его вернул.
- Если каждый шаг содержит `track`, Roadmap показывает кнопки назначенных треков
  и прогресс выбранного трека. Кнопки строятся по группам `steps[].track`;
  их переключение локальное и не вызывает запросов назначения или загрузки. С прежним API без этого поля показывает все шаги
  единым списком, сохраняя серверный порядок. Принадлежность по ID не вычисляется.
- Доступны виды «Этапы» и «По неделям»; выбранные трек, шаг и вид сохраняются
  отдельно для пользователя. Завершённые треки остаются доступны.
- «Спросить у AI-buddy» открывает новый чат с подготовленным вопросом о выбранном шаге.
  Диалог создаётся после отправки вопроса пользователем.
- Если в ответе есть `proposal`, отображается карточка с кнопкой «Отправить заявку».
  Во время отправки кнопка заблокирована; статус `pending_dispatch` отображается
  как «В очереди». Отправка заявки не отмечает шаг выполненным.
- Уведомления WebSocket инициируют обновление истории и Roadmap.
  Решение по заявке отображается сообщением от сервера.

Левую панель на широком экране можно растягивать за правый край. Ширина
сохраняется в браузере; двойной клик по границе сбрасывает размер.
При фокусе на границе стрелки меняют ширину, Home/End задают пределы.
На узких экранах панель открывается поверх чата без ручного изменения ширины.
