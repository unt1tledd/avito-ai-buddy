# Проверки фронтенда

Запуск из `frontend`: `npm test`. Отдельно `npm run build` проверяет TypeScript и production-сборку.

Набор `onboarding.test.mjs` содержит 40 тестов на Node.js test runner. TypeScript-модули загружаются через `transpileModule`, HTTP заменён заглушками, компоненты проверяются через `renderToStaticMarkup`. Проверка типов выполняется сборкой, а не транспиляцией тестов.

Покрываются:

- API Roadmap: отсутствие плана, ошибки, текущие шаги из серверного контекста, группировка и совместимость со старым форматом; отметка выполнения и её отмена.
- Представление Roadmap: прогресс выбранного трека, завершённые треки, доступность переключателей, переход к следующему серверному шагу после выполнения.
- Превью Roadmap: следующий незавершённый шаг в том же треке; сохранение загруженных данных при обновлении и ошибке обновления.
- API чата: текст, ключ идемпотентности, выбранный диалог, история и преобразование предложений доступа.
- Заявки: состояния карточек, подтверждение, ошибки, отсутствие автоматического завершения шага; финальные решения не откатываются при объединении сообщений.
- Сбор заявок: все страницы истории, выбор свежей записи, частичная недоступность, повторяющийся page token, максимум четыре параллельных чтения, разделение одинаковых ID по чатам, пустой список.
- Обновление сессии при 401: единственный повтор, сохранение тела и диалога, передача обновлённого токена и cookies.
- Уведомления: фильтрация событий и диалогов, объединение серий событий, последовательное выполнение и остановка очереди. Время в тесте очереди виртуальное.
- Текст ответов: скрытие служебных меток, перевод статусов, HTML-экранирование, ссылки и источники.
- Регистрация: совпадение паролей, ограничения длины и UTF-8; форма профиля не предлагает самоназначение трека.

Ограничения: серверный рендеринг не запускает `useEffect` и обработчики кликов. Этот набор не подтверждает работу браузерных диалогов, фокуса, восстановления после перезагрузки, WebSocket-переподключения, CSS, мобильной компоновки или отсутствие визуальных скачков. Для этого нужна отдельная браузерная проверка. Реальные серверные сервисы и качество ответов ИИ этими тестами не проверяются.
